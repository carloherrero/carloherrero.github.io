Privacy Policy

CPA Intake Assistant · Last updated October 11, 2026

CPA Intake Assistant ("the app") is a document-intake tool operated by Carlo Herrero. The current version is a demonstration that connects only to a demo mailbox controlled by the operator and uses test data.

What the app accesses

With the mailbox owner's permission, granted through Google sign-in, the app reads messages and attachments in a single designated intake mailbox. It uses this access only to find documents sent to the firm for tax preparation.

How the information is used

  • Attachments are stored in the firm's own database and file storage so firm staff can review them.
  • To identify the type of document, the app extracts text and removes personal details such as names, email addresses and identification numbers. Only that redacted text may be sent to an AI model provider.
  • Matching a document to a client is done by the app itself, not by an AI model.

Sharing

The app does not sell personal information and does not use it for advertising. Information is shared only with service providers needed to run the app, such as hosting, database and AI model providers, and only for that purpose.

Google user data

The app's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Documents are kept for as long as the firm needs them for its work. The mailbox owner can revoke the app's access at any time from their Google Account under Security, Third-party connections. To ask for data to be deleted, contact us at the address below.
